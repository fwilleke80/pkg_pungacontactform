# Punga Contact Form

A simple contact form for Joomla 6, available as both a menu item and a site module.

Install the package installer ZIP through Joomla's extension installer, then configure the recipient in **Components → Punga Contact Form → Options**.

The form includes built-in spam protection, Joomla CAPTCHA support, and a message moderation dashboard. English and German translations are included.

Developer documentation, setup details and security notes are in [`docs/`](docs/). Release history is in [`CHANGELOG.md`](CHANGELOG.md).
